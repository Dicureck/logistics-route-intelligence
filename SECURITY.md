# Security and dataset policy

This laboratory is an **independent, synthetic demonstration**, not a customer system.

- Do not upload proprietary source, real addresses, customer transactions, credentials, authentication tokens, employee information, or production database exports.
- All included data and business entities are generated specifically for this project.
- The default workflow runs offline; it does not connect to external systems.
- Report issues privately to the repository maintainer, without posting secrets in a public issue.
- This repository is provided for educational and portfolio use; its outputs are not production business advice.
