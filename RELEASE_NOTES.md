# Logistics & Route Intelligence · v0.1.0

First official public source release of an **original, reproducible lab using only invented data**.

## Included

- Deterministic fictional last-mile deliveries and regional operational KPIs.
- Synthetic delivery SLA, geofence-oriented and actual-versus-planned distance analyses.
- Python source, reproducible fixtures, automated tests and an offline illustrative dashboard.
- A separately generated [interactive portfolio demo](https://dicureck.github.io/?demo=logistics#lab) with filters and CSV export.

## Verification

This version is created only after the source at the exact tagged commit passes the repository's **Lab CI** GitHub Actions workflow. The workflow covers the lab's documented automated checks.

## Limitations

No customer delivery data, real geofencing service, production SLAs, or native published Power BI workbook. The interactive web demo and repository examples use separate fictional datasets.
